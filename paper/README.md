# Paper

Associated manuscript:

**Projeto, Modelagem e Validação Funcional de um Sistema Compacto de Chute Eletromagnético para Robôs da RoboCup Small Size League**

## Current evidence policy

The consolidated manuscript separates:

- analytical calculations;
- LTspice simulation results;
- measured LCR parameters;
- functional hardware observations;
- quantitative experiments still pending.

## Consolidated headline results

- 12.6 V input model with 50 mΩ series resistance;
- approximately 200 V on 1000 µF;
- approximately 20 J stored energy;
- approximately 445 ms simulated charge time;
- 5.045 A average and 5.815 A RMS simulated input current;
- 21.705 A simulated solenoid peak;
- approximately 60 kHz dominant recharge spectral component;
- functional validation of charging, ready indication, triggering, actuation, and recharge;
- experimental LCR characterization of the solenoid.

The verified LaTeX source, bibliography, figures, and compiled PDF should be placed here as one internally consistent revision. Earlier drafts with superseded numerical values should be archived rather than mixed with the submission version.
